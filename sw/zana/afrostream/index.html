AfroStream kwa Kiswahili

Gundua watayarishi wa Afrika kutoka data ya umma, chunguza freshness na tumia snapshot iliyowekwa wazi API inaposhindwa.

Orodha iliyopakiwa

Chanzo na freshness. API za umma za AfroStream husomwa wakati wa kufungua ukurasa. API ikishindwa, faili ya fallback yenye lebo, tarehe ya mapitio na hali ya metrics hutumika; ikiwa zote zimeshindwa hakuna data ya kubuni inayooneshwa.
Mpaka wa matumizi. Data ya API inaweza kubadilika au kukosekana. Snapshot ya fallback huoneshwa kwa lebo na tarehe yake; thibitisha wasifu kwenye jukwaa asili.
