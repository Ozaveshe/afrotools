API ya AfroTools

Mwongozo wa API ya AfroTools

Jaribu ombi la kwanza kwa ufunguo wa majaribio, kisha soma matokeo ya mfano kabla ya kuunganisha programu yako.

Jaribu hesabu ya mshahara

Mfano huu unatuma mshahara wa mfano wa naira 500,000 kwa mwezi nchini Nigeria. Ufunguo unaoanza na afro_test_ unarudisha data ya majaribio inayoweza kurudiwa.

curl -X POST "https://afrotools.com/api/v1/tax/paye" -H "x-api-key: afro_test_demo123456789" -H "Content-Type: application/json" -d '{"country":"NG","grossMonthly":500000}'

Soma jibu

Ukipata 200 OK, angalia status, sandbox na result.netMonthly kwenye JSON. Thamani ya mshahara halisi katika mfano huu ni ya majaribio.
