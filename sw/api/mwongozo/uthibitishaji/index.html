Mwongozo wa API

Uthibitishaji wa maombi ya API

Tuma ufunguo wako katika kichwa cha ombi kinachoitwa x-api-key. Chagua ufunguo wa majaribio au wa matumizi halisi kulingana na kazi yako.

Tumia kichwa cha ombi

x-api-key: afro_test_demo123456789

Ufunguo huu wa mfano ni wa majaribio. Unaweza pia kutumia kigezo cha URL api_key kwa jaribio la haraka. Tumia kichwa cha ombi kwa programu inayohudumia watumiaji.

Ufunguo wa matumizi halisi

Ingia kwenye dashibodi ya API na uthibitishe anwani yako ya barua pepe ili kuunda ufunguo unaoanza na afro_live_. Weka ufunguo huo kwenye seva yako. Usiweke kwenye JavaScript ya kivinjari, programu ya simu inayosambazwa kwa umma, kumbukumbu za mfumo au picha za skrini.

Vifunguo vya washirika hutumika kwenye seva na vina mipaka ya huduma na idadi ya maombi iliyokubaliwa. Ukipokea 401 INVALID_API_KEY, hakiki ufunguo na huduma unayoomba.
