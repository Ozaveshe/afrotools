Know the network boundary

Local phrasebook first; cloud translation is a separate choice

Built-in phrasebooks: browsing and phrase search stay on the page and do not need cloud translation.

Optional cloud translation: supported routes start with cloud translation off. The exact text entered is sent to AfroTools and the named translation provider only after explicit opt-in for that page session. Do not enter private, confidential, legal, health, school, employment, account or client text.

Fail-closed: without consent—or when the cloud request is unavailable—the cloud action does not run. The built-in phrasebook remains available, and consent is not remembered for a new page session.

Questions before you choose

Language tool FAQ

Will browsing a phrasebook send my text to a cloud service?

No cloud translation is needed to browse or search the built-in phrasebook. On supported routes, the separate cloud action remains off until you opt in for that page session.

What exactly is sent after cloud-translation consent?

The exact text entered is sent to AfroTools and the named external translation provider. Do not use cloud translation for private or confidential content. Provider and fallback choices are shown on the individual route.

What happens when consent is missing or the request fails?

The cloud action fails closed: it does not send the text. The local phrasebook remains available. Consent is not automatically carried into a new page session.

Can I rely on a result for an official or public document?

Not without qualified review. Translation, transliteration, spelling, tone and dialect can change meaning. Use a qualified translator or appropriate reviewer for important communication.
