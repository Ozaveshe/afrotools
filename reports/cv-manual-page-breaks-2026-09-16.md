# CV manual page breaks — bounded candidate

The education break previously produced the same two JPEG page images as a comfortable export in the EN complete Pan-African Minimal fixture. The raster paginator ignored the CSS print-break class; heading-text matching also depended on English words.

Built-in sections now carry stable semantic identifiers in all 30 renderers. User custom headings keep the custom identifier, including a heading named Education. The raster capture records requested section offsets and the paginator cuts at those offsets. No default density, field visibility, automatic split avoidance, or print sizing behavior is changed by this candidate.

Validation: seven node model tests pass, including 30 templates × three locales and custom-heading isolation. Three Chromium tests at 320px pass with actual EN/FR/SW Pan-African Minimal downloads: the first PDF image height matches the education offset and every image remains inside A4. This does not establish every manual-break combination across all templates. Existing 120-artifact evidence remains evidence for default exports; the manual-break outputs are separate.

Open mode findings: one-page density reduces the name too severely; optional-section hiding still needs native semantic handling; print sizing and arbitrary unbroken text need further verification. No whole-CV acceptance or deployment is claimed.
