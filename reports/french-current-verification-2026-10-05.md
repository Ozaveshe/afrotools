## Owners and compatibility

- `scripts/build-french-free-app-acceptance.js` and `data/audits/french-free-app-acceptance.json`: schema 3 explicitly marks the registry `acceptanceKind: historical`; the category evidence catalog also declares its historical meaning. `totals.acceptedApps` and `entries.status: accepted` remain historical compatibility fields; `historicallyAcceptedApps` is explicit. - `data/localization/fr-document-pdf-parity.json`: only invoice/CV gain verification contracts. They name generators, shared inputs, required executed checks, feature/export coverage, pending reviews and unresolved regressions. The contracts do not change served UI. Undeclared apps remain `needs-revalidation`.
- `scripts/lib/source-fingerprint.js`: reusable SHA-256 helper over sorted repository-relative paths, raw file bytes and canonical source-contract JSON. Missing/escaping paths fail closed.
- `scripts/lib/french-free-app-verification.js`: captures English/localized HTML, direct served JS/CSS, available readable owners, declared lazy/shared inputs, generator/test/runner sources, dependency lock and test-server contract. Named reviewer evidence also participates in the digest; nonexistent review evidence blocks verification. This is a declared dependency graph, not a general JavaScript dependency analyzer. Future lazy dependencies must be added to their owner contract. CV currently binds 160 source files and invoice 54.
- `scripts/run-french-free-app-verification.js`: `npm run fr:verification:run`, optionally `-- --app=cv-builder` or `-- --app=invoice-generator`. Captures before/after snapshots, records the tested Git revision plus dirty-workspace flag, executes named checks, and replaces selected old passes with an in-progress record before execution. Interruption leaves a nonaccepted state. A later failure supersedes the old pass for that owner. Only final passed results count; skips, zero selected cases, retries/flaky results, invalid output and empty Node executions fail closed. One route failing does not falsify another route's actual passed result.
- `reports/french-free-app-current-verification-receipts.json`: schema 1 execution artifact, not route authority. Stores English ID, locale, authoritative route, tested revision, dirty flag, timestamps, full path/hash manifest, before/after drift flag, final check statuses, test-environment boundary and `production: null`. No raw document data or downloaded fixture content is recorded. This batch ran from a dirty implementation workspace; the fingerprint binds those actual bytes, and the receipt does not pretend the new implementation was already in its tested Git revision.

For example, current evaluation uses `sourceFingerprint`, `testedRevision`, `checks`, `editorialReview`, `workflowReview`, `unresolvedRegressions`, `production` and `reasons`. Its status is `verified`, `partial`, `not-run`, `needs-revalidation` or `blocked`; `workflowStatus` separately describes the declared engineering checks.
