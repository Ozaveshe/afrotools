# CV one-page content choice — bounded verification

The previous one-page CSS applied a 90% font size to the name relative to a small parent, shrinking a 25px heading to roughly 7px. Removing that override preserves the template's readable heading. The option remains an attempt and can produce multiple pages.

Optional hiding now uses built-in semantic section identifiers in every locale. Each PDF or print action asks in EN/FR/SW whether to omit references, awards, volunteering, interests, memberships and custom sections from that output. Cancel retains all sections. A prior saved hide flag cannot silently authorize the next export. Saved form data remains unchanged.

Three Chromium tests at 320px passed with six actual PDF downloads: accept and cancel in each locale, including an old stored hide flag. They verify localized prompts, name size at capture, optional section visibility, unchanged form data and physical image bounds. The EN retained-content PDF was rendered with Poppler and visually inspected: readable full-size name and visible reference tail. Six PDFs are preserved locally under ../cv-one-page-fixed-proof. This is representative Pan-African Minimal mode evidence, not all-template one-page acceptance.

Manual-break verification is separate. Default 120-artifact matrix, print physical sizing, automatic split avoidance and arbitrary unbroken content remain separate evidence dimensions.
