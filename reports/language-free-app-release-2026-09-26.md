## Risk Notes

- Privacy: sensitive document processing remains local by default; no new server/AI upload path or account gate is introduced. Test fixtures are synthetic.
- Accessibility: selected mobile reflow, native labels, keyboard and status behavior are verified. Raster PDFs can lose selectable text and accessibility structure; visual signatures are not cryptographic signatures.
- SEO/routes: existing routes/canonicals are preserved and hreflang passes. Native discovery copy improves consistency; no click/ranking improvement is claimed. French baseline for Aug 29–Sep 25 is 407 clicks/50,079 impressions/0.81% CTR; Swahili is 34/1,839/1.85%, from the linked Search Console report.
- Analytics: existing event names remain; launch defaults and test-specific network interception are recorded separately. These tests do not prove analytics ingestion.
- Source freshness/confidence: fixed tariff fixtures prove behavior, not current official rates. French energy data remains stale when its actual age exceeds the existing rule. The 20-app smoke does not independently prove every arithmetic engine or actual printing.
- Generated output: the later build changed 1,644 files: 1,640 asset-version replacements, the repaired blog's added fingerprint, two claim-count reports and Swahili PDF Repair head/fingerprint normalization. No deletion or unsupported freshness reset.
- Remaining scope: arbitrary PDF geometry/readers/resource limits, English recommendation artwork and some unchanged Swahili fallback vocabulary remain unproven or explicitly carried. Separate BOQ discovery and Burkina Faso payroll guardrail work are not part of this candidate.
