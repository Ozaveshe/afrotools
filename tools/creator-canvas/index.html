Questions

Can I upload photos or logos?

No. This focused version creates a text-and-color graphic and does not advertise file uploads.

Can I download JPG or share directly to social apps?

No. The verified image output is PNG. JSON and TXT support project handoff.

Does my copy leave the browser?

No. The workspace has no AI, Supabase or application API request for the values you enter.
