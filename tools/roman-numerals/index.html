How to convert numbers to Roman numerals

Roman numerals build each value from seven letters — I (1), V (5), X (10), L (50), C (100), D (500) and M (1000) — written from largest to smallest and added together. To convert a decimal number by hand, break it into thousands, hundreds, tens and units, then swap each part for its symbol.

  1. Take the biggest place value first. For 2024, start with 2000 = MM.
  2. Convert the next place down: 20 = XX, then 4 = IV (subtractive form of 5−1).
  3. Join the parts in order: MM + XX + IV = MMXXIV.

In the modern convention used by this tool, I, X, C and M can repeat up to three times, while V, L and D do not repeat. The accepted subtractive pairs are IV, IX, XL, XC, CD and CM. Historical inscriptions and some clock faces use variants such as IIII; this checker deliberately reports those as non-canonical.

How the converter checks Roman numerals

This page accepts one clearly stated modern convention from 1 to 3999. Roman numeral usage has varied across periods and contexts, so “invalid” here means “outside this converter’s convention,” not “never used historically.”

  • Decimal input is converted with the standard M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, and I sequence.
  • Roman input is parsed, then converted back to Roman to confirm the notation is canonical.
  • Batch mode uses the same validator for every line and reports bad rows rather than silently dropping them.
  • Zero, negative numbers, fractions, overlines and historical variants are outside this tool’s scope.

Frequently asked questions

What range does this converter support?
It supports modern conventional forms for whole numbers from 1 to 3999. Zero, negatives, fractions, variant spellings and overline notation are outside its scope.
Which subtractive pairs does it accept?
IV, IX, XL, XC, CD and CM. Forms such as IL, IC and VX are rejected because they are outside the convention used here.
Why might a clock show IIII instead of IV?
Some clock faces use IIII as a design tradition. This converter deliberately validates the modern conventional form IV, so it reports IIII as a variant.
Does this page upload my entries?
No. Conversion, batch processing and quiz checking run in the browser. The page does not save or upload the values you enter.
