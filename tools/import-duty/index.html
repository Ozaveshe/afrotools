Scope and privacy

Planning estimate, not a declaration

The calculator cannot guarantee a charge, classify a product, approve clearance or predict port costs. Preferential origin, exemptions, trade remedies and specific duties require declaration-level review.

All calculations and exports run in your browser. Analytics receive only event names and non-sensitive choices such as destination, origin, goods type and whether an override was used—never invoice descriptions or amounts.

Common questions

Import and landed-cost FAQ

What is included in landed cost?

This estimate combines supplier value, freight, insurance, source-backed customs charges and any optional local costs you enter.

Does origin country change import duty?

Not automatically. The calculator never assumes preferential duty from origin. South African origin is used only for the documented VAT-uplift exception.

Can I calculate the cost of importing a vehicle?

Vehicle calculations use a separate AfroTools workflow because age, engine, valuation and environmental rules differ from general goods.

Quick answer

Import costs across Africa usually start with CIF, then stack customs duty, VAT, and market-specific levies. If you only budget for the headline duty rate, you usually underprice the true landed cost.

What costs are usually missed on import budgets?
Freight, insurance, customs levies, VAT on a duty-inclusive base, port charges, and FX swings are the most common blind spots.
When should I use the calculator?
Use it before placing the order, again when freight is confirmed, and once more before final customs clearance.
