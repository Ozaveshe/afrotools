AfroTools ní Yorùbá

Bí o ṣe lè gba òṣùwọ̀n èlé ilé ìfowópamọ́ àárín gbùngbùn

Lo API yìí láti wo òṣùwọ̀n èlé ìlànà owó, ìsọfúnni nípa ìlọsíwájú iye ọjà, orúkọ ilé ìfowópamọ́ àárín gbùngbùn àti orísun dátà.

Àpẹẹrẹ fún Nàìjíríà

Lo GET /api/v1/rates/central-bank. Nínú àpẹẹrẹ yìí, country=NG yan Nàìjíríà.

curl "https://afrotools.com/api/v1/rates/central-bank?country=NG"

Ṣàyẹ̀wò orísun

Ka orúkọ ilé ìfowópamọ́ àti orísun tó wà nínú ìdáhùn kí o tó lo òṣùwọ̀n náà. Tí o bá fẹ́ mọ iye owó orílẹ̀-èdè kan ní owó orílẹ̀-èdè mìíràn, wo àlàyé pàṣípààrọ̀ owó ní Gẹ̀ẹ́sì.

Ìtumọ̀ àwọn àṣìṣe API · Àlàyé ìmọ̀ ẹ̀rọ ní Gẹ̀ẹ́sì
