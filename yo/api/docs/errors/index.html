AfroTools ní Yorùbá

Àwọn àṣìṣe API àti bí o ṣe lè tún wọn ṣe

Wo nọ́mbà ìdáhùn HTTP àti ìsọfúnni inú JSON láti mọ ohun tí o lè ṣe lẹ́yìn tí ìbéèrè rẹ kò bá ṣàṣeyọrí.

Àpẹẹrẹ ìdáhùn

{"error":"Invalid or missing API key","code":"INVALID_API_KEY"}

Ka error àti code. Àwọn ọ̀nà API kan tún lè dá status àti reason padà.

400 · MISSING_REQUIRED_FIELD
Ààyè tàbí àṣàyàn tí ìbéèrè nílò kò sí. Ṣàyẹ̀wò àpẹẹrẹ ìbéèrè náà, kí o sì fi ohun tó kù sí i.
401 · INVALID_API_KEY
Kọ́kọ́ ṣàyẹ̀wò pé o fi kọ́kọ́rọ́ API tó tọ́ sínú x-api-key.
404 · INVALID_COUNTRY
API kò rí orílẹ̀-èdè, tọkọtaya owó tàbí ohun tí o béèrè. Ṣàyẹ̀wò kóòdù tí o lò.
429 · RATE_LIMIT_EXCEEDED
O ti kọjá iye ìbéèrè tí a gbà láàyè. Dúró kí o tó tún gbìyànjú.
500 · INTERNAL_ERROR
Iṣẹ́ náà kò lè parí ìbéèrè rẹ. Tún gbìyànjú lẹ́yìn ìgbà díẹ̀.
