Journal des modifications de l’API

Version 1.1 · mai 2026

Cette mise à jour a regroupé dans une même réponse les informations du compte AfroPoints utilisées par le tableau de bord, notamment l’activité et l’historique des demandes de paiement. Les réponses contenant des données de compte ont reçu des directives de cache privées pour limiter l’affichage de données périmées.

Pour une intégration avec authentification, consultez les instructions actuelles en anglais.

Version 1.0 · mars 2026

Cette version présentait les services de calcul de l’impôt sur le salaire et de la TVA, les cours de change, les prix des carburants et les taux des banques centrales.

Pour vérifier les services actuellement proposés et leurs modalités d’accès, ouvrez la référence technique en anglais. Pour les taux directeurs, consultez la rubrique des banques centrales.
