Journal des modifications de l’API

Mai 2026 · Version 1.1

Cette version améliore la synchronisation des comptes AfroPoints. Les intégrations existantes restent compatibles.

  • Une seule requête authentifiée permet de récupérer le profil, l’activité récente, les contributions récentes et l’historique des retraits. Le tableau de bord utilise cette réponse groupée.
  • Les services de profil et d’AfroPoints traitent les jetons d’accès et les cookies de session via le même mécanisme d’authentification.
  • Les réponses contenant des données de compte utilisent les directives de cache private, no-store. Si votre application conserve une copie locale, actualisez-la après une modification du profil, une contribution ou une demande de retrait.
