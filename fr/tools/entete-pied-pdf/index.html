Ce que cela couvre
  1. Six zones pour un placement indépendant à gauche, au centre et à droite.
  2. Jetons pour les numéros de page, les totaux, les dates, les noms de fichiers et les identifiants Bates.

  4. Sortie par lots sous forme de ZIP lorsque plusieurs PDF sont sélectionnés.

En-têtes et pieds de page PDF professionnels dans le navigateur

Utilisez les en-têtes et les pieds de page lorsque vous avez besoin d'un contrôle visible des documents : numéros de page, dates, étiquettes de confidentialité, noms de fichiers, notes de version ou références de style Bates. AfroTools maintient le flux de travail local et donne à chaque poste son propre champ afin que les packs formels n'aient pas besoin d'être modifiés manuellement page par page.

L'exportation préserve le contenu PDF d'origine et ajoute de nouvelles marques de texte par-dessus. Conservez le fichier source d'origine si vous avez besoin d'une version propre plus tard.
