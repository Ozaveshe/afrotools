La préparation à la production dépend toujours de l'intégration du commerçant, de l'approbation de la conformité, de l'accès au bac à sable, de la disponibilité dans les pays et des limites tarifaires du fournisseur.

Utilisez le répertoire comme un transfert d'intégration, et non comme une promesse d'accès.

Chaque entrée API est un point de départ pour l’évaluation technique. Ouvrez les documents du fournisseur, copiez la demande de démarrage, enregistrez-la dans API Tester, puis confirmez les informations d'identification, les prix, les limites, la conformité et la disponibilité sur le marché en direct avec le fournisseur avant la production.

Avant de tester

Utilisez uniquement les informations d'identification du bac à sable ou les points de terminaison publics. Ne collez jamais de paiement en direct, de portefeuille, d'identité ou de secrets bancaires dans des captures d'écran ou des rapports partagés.

Avant le lancement

Confirmez l'intégration du commerçant, la gestion des rappels/webhooks, les listes autorisées d'adresses IP de production, les règles de données, les limites de débit et la disponibilité des produits spécifiques au pays.

Avant de choisir

Comparez les documents officiels du fournisseur avec votre marché, le consentement de l'utilisateur, le processus d'assistance et les besoins en matière de gestion des pannes. Les scores ici sont des ajustements éditoriaux et non des données de disponibilité.

FAQ sur l'annuaire API africain

A quoi sert ce répertoire ?

Il aide les développeurs à présélectionner les paiements africains, l'argent mobile, les télécommunications, l'identité, la banque ouverte et cartographie les API avec des liens vers des documents, des notes d'authentification, l'état du bac à sable et des notes sur les risques de production.

Puis-je tester ces API ici ?

Vous pouvez copier les appels de démarrage cURL ou enregistrer les demandes dans API Tester. Vous avez toujours besoin des informations d'identification du bac à sable du fournisseur ou d'un accès public au point de terminaison.

AfroTools garantit-il la disponibilité ?

Non. Confirmez les prix, l’approbation de conformité, les limites, les informations d’identification, l’assistance nationale et l’accès à la production directement avec chaque fournisseur.
