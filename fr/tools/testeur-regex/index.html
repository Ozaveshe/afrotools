Que vérifier

  • Méthodologie : exécutez l'expression régulière JavaScript sur un exemple de texte, inspectez les correspondances et les captures, puis examinez le remplacement et la sortie du code généré.
  • Testez des échantillons réalistes valides, invalides, vides, longs, Unicode et extrêmes avant d'appliquer un modèle en production.
  • Examinez les indicateurs, les groupes de capture, les ancres, la sortie de remplacement et le risque de retour en arrière catastrophique.
  • Confirmez les formats officiels des numéros de téléphone, des pièces d'identité, des numéros fiscaux, des références de paiement ou des codes gouvernementaux avant de refuser des utilisateurs.

Limites

  • Avertissement : utilitaire d'expression régulière JavaScript local uniquement, et non un validateur officiel ni une garantie de sécurité.
  • Différents langages et moteurs de base de données peuvent interpréter différemment la syntaxe des regex.
  • Ne collez pas de journaux sensibles ou de données personnelles dans des exemples de modèles partagés.
