Utiliser cette estimation

  • Comparez la fourchette à un contrat ou à un devis écrit ; ce n’est pas un barème obligatoire.
  • Confirmez les livrables, les révisions, les autorisations, les visites de chantier, les prestations techniques, les taxes et les débours.
  • Vérifiez l’inscription du professionnel dans le pays du projet et pour la catégorie de travaux concernée.
  • Conservez le JSON pour rouvrir les données ; le PDF, le CSV et le TXT sont des copies de planification.

Questions fréquentes

Le pays détermine-t-il le taux des honoraires ?

Non. Le pays fournit seulement un nom et une indication de devise. Tous les taux proviennent de vos saisies.

S’agit-il d’un devis officiel ou d’une autorisation ?

Non. Il s’agit d’une estimation de planification. Le professionnel et l’autorité locale confirment l’inscription, la mission, les honoraires, les taxes et les autorisations.

Les données du projet sont-elles envoyées à un serveur ?

Non. Le calcul, les brouillons et les exports restent dans ce navigateur.

Cette estimation remplace-t-elle une validation professionnelle ?

Non. Elle structure une première décision. Les documents d’exécution, notes de calcul, installations et devis doivent être contrôlés par les professionnels compétents.

Mes données sont-elles envoyées à une IA ?

Non par défaut. Le calcul déterministe et les exports fonctionnent localement. Toute assistance d’IA doit rester facultative, expliquer son transfert de données et demander votre consentement.
