Questions fréquentes

D’où viennent les frais utilisés ?

Ils viennent de votre saisie. Les prestataires peuvent modifier leurs frais selon le montant, le canal, le pays et le profil du client.

Que signifie le taux de frais effectif ?

Il s’agit du total des frais saisis divisé par le montant envoyé, exprimé en pourcentage. Cette mesure facilite la comparaison entre un forfait et un pourcentage.

Le résultat inclut-il tous les frais possibles ?

Non. Ajoutez ou comparez séparément les frais de retrait, les taxes, les frais du destinataire et les frais de compte indiqués dans le devis.

Le choix du pays charge-t-il des frais en direct ?

Non. Le pays sert uniquement à afficher un code de devise. Aucun service de prix, portefeuille ou banque n’est contacté.
