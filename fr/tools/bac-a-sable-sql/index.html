SQL FAQ sur les aires de jeux

  
Comment dois-je l’utiliser ?
Choisissez un ensemble de données, exécutez SQL, inspectez les résultats ou interrogez les plans, puis copiez le résumé de révision ou exportez le résultat pour la pratique et le contrôle qualité.
Que dois-je vérifier ?
Vérifiez l'ensemble de données sélectionné, l'avertissement de requête de mutation, le nombre de lignes de résultat, le plan d'explication, les commentaires de défi et les fichiers exportés.
Est-ce connecté à une base de données active ?
Non. Il exécute SQLite localement dans votre navigateur sur des données groupées ou importées.
