## Add, correct or withdraw
1. Read the official instrument and exceptions; a news alert, ILO observation or changed content hash is only a research lead. Independently author public-safe text. Reuse an exact maintained official-source ID; extend that ledger through its maintained owner for a new category/source. The current checker intentionally supports only the HR/payroll ledger.
2. Obtain explicit public editorial approval of the content, official evidence, country, public engine type and dates. Record the decision ID and source-review receipt SHA. Private Gazette verification or report send-consent NEVER grants publication. No automatic transfer from private reports, Gazette, review_queue or MOCK fixtures exists.
3. Preserve date-only publication/effective dates and actual reviewed_at. Never substitute fetch/build time, convert hourly rates to invented monthly values, or imply relevant calculator links were updated. Reference keys are navigation only.
4. Maintain a 90-day review-due interval and review new official notices sooner. A due record remains historical with a visible review-due label; it is not silently refreshed or removed. New source evidence and explicit review are required to advance reviewed_at.
5. Retain older events. Mark superseded with an existing successor ID and correction note; mark withdrawn with a correction note. Preserve source history in Git. Do not remove a valid past record merely because its rate has a successor. No promise of full country coverage, review turnaround, automatic calculator updates, subscription delivery or legal advice is made.
6. Run focused checks, review source and any owner-generated outputs separately, then hand off through the existing sole publisher. The publisher's accepted release must independently prove dist JSON inclusion, SHA/MIME/status, no redirect/SPA substitute, and actual browser rendering of the same event. Release evidence records actual commit/deploy/time. Do not fabricate future deployment fields in source JSON.

## Failure and integration
A valid empty dataset means no records in this editorial list, not no law changes. Header/body decode share an eight-second abortable budget. HTTP/MIME/schema/size failure, offline state and timeout remain honest; retry is explicit and coalesced. No fallback to MOCK, private data or another origin. The last deployed dataset retains its original review dates if later publication fails.
