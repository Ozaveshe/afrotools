Fuel Prices

Look up fuel price references by country. Check when a price was observed and whether it applies nationally or to a specific market.

GET https://afrotools.com/api/v1/fuel/prices
API keys are optional for this endpoint. Send a live key in the x-api-key header for authenticated limits. Test keys return deterministic sandbox data. Learn more

Request Parameters

ParameterTypeDescription
countrystringOptional ISO 3166-1 alpha-2 code. Omit for a country list.
regionstringOptional list filter. Use west, east, south, north or central.
sortstringOptional list order. Use petrol_asc, petrol_desc, diesel_asc, diesel_desc or name.
includestringSet to markets to add published market references for the selected country or country list.
historystringUse with country for a historical series where available. For example, country=NG&history=12m.

Latest response fields

FieldTypeDescription
country / countriesobject / arrayCountry records contain code, name, currency and product references such as petrol.price in local currency and petrol.usd, when present. Sandbox fixtures use petrol.local.
collected_atstring or nullTimestamp of the data collection. The age of an individual price depends on its own observation date.
price_provenance.country_snapshot_datestring or nullSnapshot date for a country record. This date can differ from the observation date of each product.
price_provenance.products.*objectIncludes observed_at and source_url. A null value means that the corresponding product detail was unavailable.
markets[]arrayOpt-in market records. Check the market name and granularity before using a price for a specific location.
markets[].fuels[].reference_statusstringavailable is eligible as a dated reference. historical is outside its validity window. unavailable cannot be used as a price reference. Use the product source and dates for context.

Market references may be empty for some countries. The sandbox and historical endpoints have separate response shapes.

Error Responses

StatusDescription
400Unsupported region.
401Supplied API key is invalid.
404Country or historical series unavailable.
429Rate limit exceeded.
503Fuel dataset temporarily unavailable.
