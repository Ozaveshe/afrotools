Latest Rates

Get a dated exchange-rate reference for a supported currency pair.

GET https://afrotools.com/api/v1/fx/rates
API keys are optional. Supply an x-api-key header for authenticated limits. Test keys return deterministic sandbox data. Learn more

Request Parameters

ParameterTypeDescription
base optional string Base currency code (e.g., USD, EUR, GBP).
target optional string Quote currency code (e.g., NGN, KES, ZAR).
amount optional number Amount to convert. Omit to get the rate without an amount conversion.
days optional integer Request a stored historical series for a pair, for example days=30. Omit for the latest reference.

Response Fields

FieldTypeDescription
basestringBase currency code.
targetstringQuote currency code.
ratenumberIndicative reference rate, or null when the pair is unavailable.
amountnumberInput amount, when provided.
updated_atstringTimestamp of the source snapshot. Check qualification for the observations used for a pair.
sourcestringSource of the snapshot.

Error Responses

StatusCodeDescription
401AuthenticationSupplied API key is invalid.
404Unavailable resourceUnsupported currency or missing historical series.
429Rate limitRate limit exceeded.
503Rate unavailableA live reference could not be qualified. For an expired observation, the response reports expired-fx-observation and omits any usable conversion. Retry after the provider refresh.
Request Examples
curl "https://afrotools.com/api/v1/fx/rates?base=USD&target=NGN" \ -H "x-api-key: afro_live_your_key_here"
const res = await fetch( "https://afrotools.com/api/v1/fx/rates?base=USD&target=NGN", { headers: { "x-api-key": "afro_live_your_key_here" } } ); const data = await res.json(); console.log(`1 USD = ${data.rate ?? "unavailable"} NGN`);
import requests resp = requests.get( "https://afrotools.com/api/v1/fx/rates", params={"base": "USD", "target": "NGN"}, headers={"x-api-key": "afro_live_your_key_here"} ) data = resp.json() print(f"1 USD = {data.get('rate', 'unavailable')} NGN")
const axios = require("axios"); const { data } = await axios.get( "https://afrotools.com/api/v1/fx/rates", { params: { base: "USD", target: "NGN" }, headers: { "x-api-key": "afro_live_your_key_here" } } ); console.log(`1 USD = ${data.rate ?? "unavailable"} NGN`);
$ch = curl_init( "https://afrotools.com/api/v1/fx/rates?base=USD&target=NGN" ); curl_setopt($ch, CURLOPT_HTTPHEADER, [ "x-api-key: afro_live_your_key_here" ]); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); $response = curl_exec($ch); curl_close($ch); $data = json_decode($response, true); echo "1 USD = " . ($data["rate"] ?? "unavailable") . " NGN";
