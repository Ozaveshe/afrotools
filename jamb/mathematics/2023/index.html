Count the distinct arrangements of all eight letters in SYLLABUS. Arrangements need not form dictionary words.

  1. (8 − 1)!
  2. 8!/2!
  3. 8!/(2! × 2!)
  4. 8!
Answer and explanation

C: 8!/(2! × 2!)

There are eight letter positions. S occurs twice and L occurs twice; the other letters occur once. Temporarily distinguish repeated letters: there are 8! arrangements. Each actual arrangement is counted 2! × 2! times. Divide: 40320/4 = 10080.

Find the value of 16^0.16 × 16^0.04 × 2^0.2.

  1. 2
  2. 0
  3. 2^0
  4. 1/2
Answer and explanation

A: 2

Combine powers with base 16: 16^(0.16 + 0.04) = 16^0.2. Rewrite 16 as 2⁴, so 16^0.2 = 2^0.8. Multiply powers with base 2: 2^(0.8 + 0.2) = 2¹ = 2.

For a ★ b = a²b and a ◇ b = 2a + b, compute (−4 ★ 2) ◇ (7 ★ −1).

  1. −49
  2. 64
  3. 113
  4. 15
Answer and explanation

D: 15

Apply ★ inside the left brackets: (−4)² × 2 = 32. Apply ★ inside the right brackets: 7² × (−1) = −49. Apply ◇ to the two results: 2 × 32 + (−49) = 15.

Calculate the definite integral from 0 to 1 of (4x − 6x^(2/3)) dx.

  1. −5/8
  2. −8/5
  3. 8/5
  4. 5/8
Answer and explanation

B: −8/5

For a power xⁿ, increase the exponent by one and divide by that new exponent. An antiderivative is 2x² − (18/5)x^(5/3). Differentiating it returns 4x − 6x^(2/3). At 1 this is 2 − 18/5 = −8/5; at 0 it is zero. Subtract the endpoint values.

A regular polygon has an interior angle five times its exterior angle. Which polygon is it?

  1. dodecagon
  2. enneadecagon
  3. icosagon
  4. hendecagon
Answer and explanation

A: dodecagon

An interior angle and its adjacent exterior angle add to 180°. If the exterior angle is e, then 5e + e = 180°, so e = 30°. The exterior angles total 360°. Therefore the polygon has 360/30 = 12 sides, making it a dodecagon.

Rearrange y = (3x − 9c)/(4x + 5d) to make x the subject, where the required denominators are nonzero.

  1. x = −(9c − 5dy)/(4y − 3)
  2. x = (9c + 5dy)/(4y − 3)
  3. x = (9c − 5dy)/(4y − 3)
  4. x = −(9c + 5dy)/(4y − 3)
Answer and explanation

D: x = −(9c + 5dy)/(4y − 3)

Multiply by 4x + 5d to obtain 4xy + 5dy = 3x − 9c. Collect the terms containing x: 4xy − 3x = −9c − 5dy. Factor to obtain x(4y − 3) = −(9c + 5dy). Divide by 4y − 3: x = −(9c + 5dy)/(4y − 3). The original expression requires 4x + 5d ≠ 0, and this rearrangement requires 4y − 3 ≠ 0.

Find the values of x satisfying 3(x − 1) ≤ 2(x − 3).

  1. x ≤ −3
  2. x ≥ −3
  3. x ≤ 3
  4. x ≥ 3
Answer and explanation

A: x ≤ −3

Expand both brackets: 3x − 3 ≤ 2x − 6. Subtract 2x from both sides, then add 3: x ≤ −3. The inequality direction stays the same because these steps do not multiply or divide by a negative number. At x = −3 both sides equal −12, so the boundary value is included.
