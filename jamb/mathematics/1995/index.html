Question 1

Calculate 3310₅ − 1442₅.

  1. 1313₅
  2. 2113₅
  3. 4302₅
  4. 1103₅
Answer and explanation

A: 1313₅

In base ten, 3310₅ = 455 and 1442₅ = 247. Their difference is 208, which is 1×125 + 3×25 + 1×5 + 3 = 1313₅.

Question 3

A notebook is 15 cm long but is measured as 16.8 cm. Find the percentage error to two significant figures.

  1. 12%
  2. 11%
  3. 10.71%
  4. 0.12%
Answer and explanation

A: 12%

The absolute error is 16.8 − 15 = 1.8 cm. Divide by the true length and multiply by 100: (1.8 ÷ 15)×100 = 12%.

Question 9

Four players belong to both an 11-player cricket team and a 14-player rugby team. How many belong to at least one team?

  1. 25
  2. 21
  3. 16
  4. 3
Answer and explanation

B: 21

Adding the team sizes counts each shared player twice. Subtract the four overlaps once: 11 + 14 − 4 = 21 players.

Question 14

At which points does y = x² − 5x + 6 cross the x-axis?

  1. (−6, 0), (−1, 0)
  2. (−3, 0), (−2, 0)
  3. (−6, 0), (1, 0)
  4. (2, 0), (3, 0)
Answer and explanation

D: (2, 0), (3, 0)

Set y = 0 and factor x² − 5x + 6 as (x − 2)(x − 3). Hence x = 2 or x = 3, giving the two intercepts (2, 0) and (3, 0).

Question 16

  1. 3 ≤ x ≤ 4
  2. 3 < x < 4
  3. 3 ≤ x < 4
  4. 3 < x ≤ 4
Answer and explanation

A: 3 ≤ x ≤ 4

The roots are 3 and 4. Between them the two factors have opposite signs, and at the roots their product is zero. Therefore 3 ≤ x ≤ 4.

  2. a*b = a + b − ab
  3. a*b = a² + b
  4. a*b = a(b + 1)/2
Answer and explanation

Question 34

  1. 97 cm
  2. 10 cm
  3. 14 cm
  4. 17 cm
Answer and explanation

C: 14 cm

Using area = ½×PQ×PR×sin(angle P),35 = ½×PQ×10×½. Thus 35 = 2.5PQ and PQ = 14 cm. The 30° angle is included between PQ and PR.

Answer and explanation

C: 6√2 m

By the sine rule, RS/sin 30° = 12/sin 45°. Hence RS = 12×(1/2)/(√2/2) = 6√2 m. Each side is paired with its opposite angle.

Question 38

Differentiate cosec x with respect to x, with angles in radians.

  1. tan x cosec x
  2. −cot x cosec x
  3. tan x sec x
  4. −cot x sec x
Answer and explanation

B: −cot x cosec x

Since cosec x = 1/sin x, differentiation gives −cos x/sin²x. This is −(cos x/sin x)(1/sin x) = −cot x cosec x.
