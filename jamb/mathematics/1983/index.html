Question 1

If M represents the median and D the mode of the measurements 5, 9, 3, 5, 8 then (M,D) is

  1. (6,5)
  2. (5,8)
  3. (5,7)
  4. (5,5)
  5. (7,5)
Answer and explanation

D: (5,5)

Put the values in ascending order: 3, 5, 5, 8, 9. The median is the middle value, 5. The mode is the most frequent value, also 5. Therefore (M, D) = (5, 5), option D.

Question 5

If x = 1 is a root of x³ − 2x² − 5x + 6 = 0, find the other roots.

  1. -3 and 2
  2. –2 and 2
  3. 3 and –2
  4. 1 and 3
  5. –3 and 1
Answer and explanation

C: 3 and –2

Dividing by x − 1 gives x² − x − 6 = (x − 3)(x + 2). Thus the polynomial is (x − 1)(x − 3)(x + 2). Apart from x = 1, the roots are 3 and −2: option C.

Question 10

If (x + 2) and (x − 1) are factors of ℓx³ + 2kx² + 24, find ℓ and k.

  1. ℓ = −6, k = −9
  2. ℓ = −2, k = 1
  3. ℓ = −2, k = −1
  4. ℓ = 0, k = 1
  5. ℓ = 6, k = 0
Answer and explanation

A: ℓ = −6, k = −9

A factor x + 2 gives f(−2) = 0, so −8ℓ + 8k + 24 = 0, or ℓ − k = 3. A factor x − 1 gives f(1) = 0, so ℓ + 2k = −24. Substitute ℓ = k + 3 to get 3k = −27. Thus k = −9 and ℓ = −6, option A. Both −2 and 1 make the repaired cubic equal to zero.

Question 14

y varies partly as the square of x and partly as the inverse of the square root of x. Find the expression for y if y = 2 when x = 1 and y = 6 when x = 4.

  1. y = 10x²/31 + 52/(31√x)
  2. y = x² + 1/√x
  3. y = x² + 1/x
  4. y = x²/31 + 1/(31√x)
  5. y = (10/31)(x² + 1/√x)
Answer and explanation

A: y = 10x²/31 + 52/(31√x)

Write y = ax² + b/√x. The first condition gives a + b = 2. The second gives 16a + b/2 = 6, or 32a + b = 12. Subtracting gives 31a = 10, so a = 10/31 and b = 52/31. Therefore y = 10x²/31 + 52/(31√x), option A. Substitution gives 2 at x = 1 and 6 at x = 4.

Question 15

Simplify [(x − 7)/(x² − 9)] × [(x² − 3x)/(x² − 49)].

  1. x/[(x − 3)(x + 7)]
  2. [(x + 3)(x + 7)]/x
  3. x/[(x − 3)(x − 7)]
  4. x/[(x + 3)(x + 7)]
  5. x/[(x + 4)(x + 7)]
Answer and explanation

D: x/[(x + 3)(x + 7)]

Factor x² − 9 = (x − 3)(x + 3), x² − 3x = x(x − 3), and x² − 49 = (x − 7)(x + 7). Cancel the common factors x − 3 and x − 7 to obtain x/[(x + 3)(x + 7)], option D. The original expression excludes x = −7, −3, 3 and 7; cancellation does not remove those restrictions.

Question 23

If w varies inversely as V and u varies directly as w³, find the relationship between u and V, given that u = 1 when V = 2.

  1. u = 8V³
  2. u = 2√V
  3. V = 8/u²
  4. V = 8u²
  5. u = 8/V³
Answer and explanation

E: u = 8/V³

Write w = a/V and u = bw³. Substitution gives u = ba³/V³ = k/V³. Since u = 1 when V = 2, k = 1 × 2³ = 8. Therefore u = 8/V³, option E.

Question 24

Solve the simultaneous equations for x x² + y – 8 = 0 y + 5x – 2 = 0

  1. –28, 7
  2. 6, -28
  3. 6, -1
  4. –1, 7
  5. 3, 2
Answer and explanation

C: 6, -1

From y + 5x − 2 = 0, y = 2 − 5x. Substitute into x² + y − 8 = 0: x² − 5x − 6 = 0. Factor: (x − 6)(x + 1) = 0, so x = 6 or x = −1. These are the two x-values in option C; the corresponding y-values are −28 and 7.

Question 27

Find the sector angles, in order, for a pie chart representing the values 6, 10, 14, 16 and 26.

  1. 15°, 25°, 35°, 40°, 65°
  2. 60°, 100°, 140°, 160°, 260°
  3. 6°, 10°, 14°, 16°, 26°
  4. 30°, 50°, 70°, 80°, 130°
  5. None of the above
Answer and explanation

D: 30°, 50°, 70°, 80°, 130°

The total is 6 + 10 + 14 + 16 + 26 = 72. Each unit represents 360° ÷ 72 = 5°. Multiply each value by 5 to obtain 30°, 50°, 70°, 80° and 130°. They sum to 360°, so option D is correct.

Question 29

The letters of the word MATRICULATION are cut and put into a box. One of the letter is drawn at random from the box. Find the probability of drawing a vowel.

  1. 2/13
  2. 5/13
  3. 6/13
  4. 8/13
  5. 4/13
Answer and explanation

C: 6/13

MATRICULATION contains 13 letters. Its vowels are A, I, U, A, I and O: six letters. Each letter is equally likely to be drawn, so the probability is 6/13, option C. Repeated vowels each count because each letter is a separate item.

Question 32

If (2/3)^m × (3/4)^n = 256/729, find m and n.

  1. m = 4, n = 2
  2. m = -4, n = -2
  3. m = -4, n = 2
  4. m = 4, n = -2
  5. m = -2, n = 4
Answer and explanation

D: m = 4, n = -2

Rewrite the left side as 2^(m − 2n) × 3^(n − m). The right side is 2^8 × 3^(−6). Equate the exponents: m − 2n = 8 and n − m = −6. Solving gives n = −2 and m = 4, option D. Substituting these values gives (16/81) × (16/9) = 256/729.

Question 34

Factorise completely 81a⁴ − 16b⁴.

  1. (3a + 2b) (2a − 3b) (9a² + 4b²)
  2. (3a − 2b) (2a − 3b) (4a² − 9b²)
  3. (3a − 2b)(3a + 2b)(9a² + 4b²)
  4. (3a − 2b) (2a − 3b) (9a² + 4b²)
  5. (3a − 2b) (2a − 3b) (9a² − 4b²)
Answer and explanation

C: (3a − 2b)(3a + 2b)(9a² + 4b²)

Write the expression as (9a²)² − (4b²)². The difference-of-squares rule gives (9a² − 4b²)(9a² + 4b²). Factor the first bracket again: (3a − 2b)(3a + 2b)(9a² + 4b²), option C. The conjugate factors need opposite signs; repeating the minus factor does not give the original expression.
