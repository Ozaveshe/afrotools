Question 6

Given √2 ≈ 1.414, estimate 1/√2 to three decimal places.

  1. 0.141
  2. 0.301
  3. 0.667
  4. 0.707
Answer and explanation

D: 0.707

Rationalising gives 1/√2 = √2/2. Using the supplied approximation, 1.414 ÷ 2 = 0.707, to three decimal places.

Question 8

For A ⊆ B in a universal set E, simplify A ∩ (A ∩ B)′.

  1. A
  2. ∅
  3. B
  4. Σ
Answer and explanation

B: ∅

Because A is a subset of B, A ∩ B = A. Therefore the expression is A ∩ A′, which has no elements and equals the empty set.

Question 11

Factorise a²x − b²y − b²x + a²y completely.

  1. (a − b)(x + y)
  2. (y − x)(a − b)(a + b)
  3. (x − y)(a − b)(a + b)
  4. (x + y)(a − b)(a + b)
Answer and explanation

D: (x + y)(a − b)(a + b)

Grouping gives a²(x + y) − b²(x + y) = (x + y)(a² − b²). Factoring the difference of squares gives (x + y)(a − b)(a + b).

Answer and explanation

B: 1, −6

Substituting x = 1 gives p + q = −5. Substituting x = 3 gives 27p + 9q = −27. Solving gives p = 1 and q = −6.

Question 17

  3. 0 < x < 1/2
  4. 1 < x < 2
Answer and explanation

C: 0 < x < 1/2

For negative x, 1/x is negative and cannot exceed 2. For positive x, multiplying by x gives 1 > 2x, so 0 < x < 1/2.

Question 33

A conical frustum has height h and its top diameter is twice its bottom diameter. Find the height of the complete cone formed by extending its sides to a vertex below.

  1. 2h
  2. 2πh
  3. πh
  4. πh/2
Answer and explanation

A: 2h

Similar cones have heights in the ratio of their diameters. If the full height is H, the removed small cone has height H/2, so h = H − H/2 and H = 2h.

Question 35

  2. p = 3, q = 1
  3. p = 5, q = 3
  4. p = 6, q = 2
Answer and explanation

D: p = 6, q = 2

The midpoint formula gives p + q = 8 and p − 2 = 2q. Substituting p = 2q + 2 into the first equation gives q = 2 and p = 6.
